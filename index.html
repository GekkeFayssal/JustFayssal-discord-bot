Install on your device
📱 iPhone / iPad
  1. Open this page in Safari
  2. Tap the Share icon
  3. Tap Add to Home Screen
🤖 Android
  1. Open this page in Chrome
  2. Tap Install app in the menu (or the prompt)
🪟 Windows / 🍎 macOS / 🐧 Linux (desktop)
  1. Open in Chrome, Edge, or Brave
  2. Click the install icon in the address bar
  3. The app gets its own window and a desktop / Start menu / Launcher entry
Data & privacy

All data stays on your device — nothing is uploaded. The vault PIN is stored as a salted PBKDF2 hash. Biometrics use the WebAuthn standard (Face ID, Touch ID, Windows Hello, fingerprint).
